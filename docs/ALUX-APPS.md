# Alux Apps — รูปแบบแอปและการติดตั้ง

"ช่องติดตั้งแอป" ของ Alux คือระบบติดตั้ง **เว็บแอปแบบ static** ที่เก็บไว้ในเครื่อง
แล้วเปิดในแท็บของเบราว์เซอร์ผ่าน protocol ส่วนตัว `alux://`

## 1. โครงของแอปหนึ่งตัว

```
my-app/
├─ alux-app.json     # manifest (ไม่บังคับ แต่แนะนำ)
├─ index.html        # จำเป็น (หรือชื่อไฟล์ตาม entry ใน manifest)
├─ app.js
└─ assets/...
```

`alux-app.json`

```json
{
  "id": "my-app",
  "name": "แอปของฉัน",
  "version": "1.0.0",
  "description": "อธิบายสั้น ๆ",
  "accent": "#5b8cff",
  "entry": "index.html"
}
```

| ฟิลด์ | จำเป็น | ความหมาย |
| --- | --- | --- |
| `id` | ไม่ | ถ้าไม่ใส่จะใช้ชื่อโฟลเดอร์ (ถูกแปลงเป็น a-z, 0-9, `-`, `_`) |
| `name` | ไม่ | ชื่อที่แสดงในเบราว์เซอร์ |
| `version` | ไม่ | ค่าเริ่มต้น `1.0.0` |
| `description` | ไม่ | ข้อความสั้นใต้ชื่อแอป |
| `accent` | ไม่ | สีป้ายไอคอน (hex) |
| `entry` | ไม่ | ไฟล์แรกที่จะเปิด ค่าเริ่มต้น `index.html` |

## 2. ติดตั้ง

ในเบราว์เซอร์: ปุ่ม **ติดตั้งแอป** (แถบเครื่องมือ) หรือ **Alux Apps → ติดตั้งจากโฟลเดอร์**
แล้วเลือกโฟลเดอร์แอป → Alux จะคัดลอกเข้าโฟลเดอร์ข้อมูลของแอป

ตำแหน่งที่เก็บ (ดูได้ในแผง Alux Apps):

```
Windows : %APPDATA%\com.alux.browser\apps\<id>\
Linux   : ~/.local/share/com.alux.browser/apps/<id>/
macOS   : ~/Library/Application Support/com.alux.browser/apps/<id>/
Android : (app data dir)/apps/<id>/
```

ติดตั้งด้วยมือได้เช่นกัน: วางโฟลเดอร์แอปไว้ใน `apps/` แล้วกดรีเฟรชเบราว์เซอร์

## 3. วิธีที่แอปถูกเปิด

```
alux://localhost/app/<id>/index.html
```

- Windows/Android ใช้รูปแบบ `http://alux.localhost/app/<id>/index.html` ภายใน
  (Tauri แปลงให้อัตโนมัติ — ไม่ต้องแก้โค้ด)
- ทุกไฟล์ในโฟลเดอร์แอปเสิร์ฟได้ รวมถึง `.wasm`, ฟอนต์, รูป
- ตรวจ path traversal แล้ว (ขอไฟล์นอกโฟลเดอร์แอปไม่ได้)

## 4. ขอบเขตความปลอดภัย (สำคัญ)

| | เบราว์เซอร์ (chrome) | เนื้อเว็บ / แอป |
| --- | --- | --- |
| webview label | `main` | `tab-*` |
| เรียกคำสั่ง Rust (`invoke`) | ได้ | **ถูกปฏิเสธ** |

แอปจึงอ่าน/เขียนไฟล์เครื่องตรง ๆ ไม่ได้ — ถ้าต้องการความสามารถระดับนั้น
ต้องเพิ่มคำสั่งใหม่ใน `src-tauri/src/lib.rs` แล้วเพิ่มระบบขออนุญาต (permission prompt)
แยกต่างหาก อย่าเปิดให้ `tab-*` เรียกคำสั่งทั้งหมดตรง ๆ

## 5. แอปตัวอย่าง

`apps/hello-alux/` — มีปุ่มนับคลิก, ใช้ฟอนต์ระบบ และไม่เรียก API ใด ๆ
ใช้ทดสอบว่าช่องติดตั้งแอปทำงานครบวงจร
